## Task 1: Number Guessing Game 

A console game where the computer picks a random number between 1 and 100
and the player has 7 attempts to guess it.

**Features**
- Gives "too low" / "too high" hints after every guess
- Handles invalid input (text) and out-of-range numbers without losing an attempt
- Shows the secret number when the player runs out of attempts
- "Play again?" option to restart with a new number

**Concepts used:** conditional statements, while and do-while loops,
exception handling (try/catch), constants (`final`), `Random` and `Scanner`

**How to run**
javac Task1/GuessingGame.java
java Task1.GuessingGame
